# 経過簿の読み取りの検証（書式の違い・写真・PDF・Excel）

蔵ごとに書式が違う経過簿を、取り込み画面と同じ処理（`src/read-pipeline.js` と `shared/sheet-map.mjs`）で読み、正解と比べた。

## 試した書式（6種類）

| 書式 | 中身 |
|---|---|
| 標準 | 用紙どおり。日付が横、項目が縦（月日・日順・時刻・操作・品温・ボーメ・日本酒度・アルコール分・酸度・状ぼう・備考） |
| 日付が縦に並ぶ | 1行＝1日。見出しが横に並ぶ |
| 項目名が違う | 日付・醪日数・温度・BMD・SMV・アル分・酸・泡・メモ |
| 項目の順番が違う | 品温・月日・状ぼう・日本酒度・日順…と入れ替えた順 |
| 一部の項目が無い | 月日・日順・品温・日本酒度・状ぼう だけ |
| 複数のタンクを1枚に | 1行＝1つのタンクの1日。タンクの列あり（1・2・4号を4日分） |

それぞれを次の形で用意した（`sheets/`。値はすべて架空のデモデータ `public/data/season-current.json` から作り、正解は `sheets/truth.json`）。

- **手書き風の写真**：手書き風の書体（Klee One・Yomogi・Zen Kurenaido）で、字ごとに傾き・揺れ・濃さのむらを付け、机の上で少し傾けて撮った見た目
- **悪条件の写真**：字の揺れを大きくし、暗く、斜めから、ぶれて、画素の少ない（長い辺 1400px・JPEG の画質も低い）写真
- **スキャンした PDF**：同じ用紙をスキャナで取った見た目の PDF（画像の PDF）
- **Excel**：同じ表を Excel にしたもの（日付は Excel の日付、日本酒度のマイナスは数値）

## 数え方

- 正解のある欄（空欄でない欄）ごとに「正解／要確認／誤り」。正解が空欄なのに値を読んだ欄は「誤り」に足す。1枚1タンクの用紙は、タンク番号も1欄として数える。
- 見出しの対応は、Claude の推定をそのまま使った（人の確認なし）。「確認した見出し」は、Claude が対応に自信がなく、取り込み画面で蔵人に確認する見出し。

## 結果（1回目）

| 書式 | 手書き風の写真 | 悪条件の写真 | スキャンした PDF | Excel | 確認した見出し |
|---|---|---|---|---|---|
| 標準（用紙どおり・日付が横） | 100.0%（67/67） | 100.0%（67/67） | 100.0%（67/67） | 100.0%（67/67） | なし |
| 日付が縦に並ぶ | 100.0%（59/59） | 100.0%（59/59） | 100.0%（59/59） | 100.0%（59/59） | なし |
| 項目名が違う（BMD・SMV・アル分 など） | 100.0%（55/55） | 100.0%（55/55） | 100.0%（55/55） | 100.0%（55/55） | 温度、BMD |
| 項目の順番が違う | 100.0%（63/63） | 100.0%（63/63） | 100.0%（63/63） | 100.0%（63/63） | なし |
| 一部の項目が無い | 100.0%（34/34） | 100.0%（34/34） | 100.0%（34/34） | 100.0%（34/34） | なし |
| 複数のタンクを1枚に | 100.0%（72/72） | 100.0%（72/72） | 100.0%（72/72） | 100.0%（72/72） | 状態（Excel） |
| **合計** | **100.0%**（350/350） | **100.0%**（350/350） | **100.0%**（350/350） | **100.0%**（350/350） | |

- 6書式 × 4つの形、合わせて 1,400 欄のすべてを正しく読んだ。見出しの対応の誤りも 0。
- 「温度」（品温か室温か）と「BMD」（多くの蔵では「ボーメ×醪日数」の別の値）は、Claude が決めつけずに確認に回した。どちらも値を見ると品温・ボーメなので、確認の画面で「はい」を押せば正しく取り込める。
- **限界**：手書きは手書き風の書体で描いたもので、本物の手書き（字のくせ、書き直し、にじみ）より読みやすい。本物の手書きの経過簿では、正解率はこれより下がるはず。読めない欄は推測で埋めず「要確認」にする作りなので、誤りより要確認が増える方向に働く。

## 測り直し方

1. `npm run dev`（netlify dev。`web/.env` の APIキーを使う）
2. 用紙をつくる：`http://localhost:8888/eval/make-sheets.html`（`?save=1` で保存の受け口へ送る）
3. 読み取って比べる：`http://localhost:8888/eval/run.html?media=photo,hard,pdf,excel&save=1&out=results.json`
4. 表にする：`node eval/report.mjs eval/results-*.json`

`eval/` は開発中だけ使うページで、本番（Netlify）には載せない。
