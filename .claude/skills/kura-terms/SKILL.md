# 醪経過表の項目と醸造用語（蔵ツイン共通の定義）

作品の中のClaudeへの指示にも同じ定義を使う（写し：`web/shared/terms.md`。片方を変えたらもう片方も変える）。

## 経過表の書式
日付が横（列）、項目が縦（行）。岐阜県産業技術センター研究報告にある醪経過表の項目に合わせる。

| 項目 | JSONのキー | 単位・型 | 意味 |
|---|---|---|---|
| 月日 | `date` | `YYYY-MM-DD` | 記録した日 |
| 日順 | `moromi_day` | 整数 | **留添の日を1日目**として数える日数。初添＝-2、踊り＝-1、仲添＝0 として扱う（留添の前日までは0以下） |
| 時刻 | `time` | `HH:MM` | 品温を測った・分析した時刻 |
| 操作 | `operation` | 文字列 | その日に行った作業（初添・踊り・仲添・留添・追水 30L・暖気入れ・櫂入れ・上槽 など） |
| 品温 | `temp` | ℃（小数1桁） | 醪の温度 |
| ボーメ | `baume` | 小数1桁 | 糖分の目安。醪の前半に測る。日を追って下がる |
| 日本酒度 | `nihonshudo` | 小数可、負の値あり | 後半に測る。日を追って上がる（−の値から＋へ）。目安：日本酒度 ≒ −10 × ボーメ |
| アルコール分 | `alcohol` | %（小数1桁） | 日を追って上がる。上槽時は17〜18%程度 |
| 酸度 | `acidity` | 小数1桁 | 1.0〜2.0程度 |
| 状ぼう（状貌） | `joubou` | 下の7段階の文字列 | 醪表面の泡の状態 |
| 備考 | `note` | 文字列 | 走り書きのメモ |

読めない・書かれていない項目は `null`。推測で埋めない。

## 三段仕込みと液面
| 段階 | 日順 | 内容 | 液面の目安（満量に対する割合） |
|---|---|---|---|
| 初添（添） | -2 | 酒母に1回目の掛米・麹・水を加える。品温12℃前後 | 約1/6 |
| 踊り | -1 | 仕込みを休み、酵母を増やす | 約1/6 |
| 仲添 | 0 | 2回目。品温9〜10℃前後 | 約1/2（3/6） |
| 留添 | 1 | 3回目。品温7〜8℃前後 | 満量（6/6）の手前 |
| 追水 | 任意 | 発酵の様子を見て水を加える | 加えた分だけ上がる |
| 上槽 | 最終日 | 醪を搾り、酒と酒粕に分ける | 0（空） |

## 状ぼう（泡の状態）の7段階（この順に進む）
筋泡 → 水泡 → 岩泡 → 高泡 → 落泡 → 玉泡 → 地

## 用語
- **留添（とめぞえ）**：三段仕込みの3回目。日順の起点
- **追水（おいみず）**：醪に水を加えること。「追い水」「加水」とも書く
- **上槽（じょうそう）**：醪を搾ること
- **暖気（だき）**：品温を上げるための操作
- **櫂入れ（かいいれ）**：櫂で醪をかき混ぜること
- **杜氏（とうじ）**：酒造りの責任者。**蔵人（くらびと）**：酒造りの働き手
